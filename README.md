# 中文新闻文本分析与词云生成

## 项目简介

本项目基于 Python 实现一个完整的中文新闻文本分析流程。

项目通过对文本数据进行预处理、中文分词、关键词统计和词云可视化，帮助用户快速分析新闻文本中的高频词汇和主要信息。

主要实现流程：

    文本输入
       |
       v
    文本清洗
       |
       v
    中文分词
       |
       v
    停用词过滤
       |
       v
    词频统计
       |
       v
    数据可视化
       |
       v
    词云生成

------------------------------------------------------------------------

## 项目功能

本项目主要包含以下功能：

### 1. 文本预处理

对原始文本进行清洗，包括：

-   删除 HTML 标签
-   去除换行符和特殊字符
-   清理无效文本信息

------------------------------------------------------------------------

### 2. 中文分词

使用 `jieba` 分词工具对中文文本进行切分。

主要步骤：

-   将连续文本转换为独立词语
-   去除无意义字符
-   根据停用词表过滤无效词汇

------------------------------------------------------------------------

### 3. 文本统计分析

对处理后的文本进行基础统计：

-   文本字符数量统计
-   分词数量统计
-   高频关键词分析

------------------------------------------------------------------------

### 4. 关键词词频分析

利用 Python `Counter` 模块统计关键词出现次数。

输出：

-   高频关键词列表
-   Top 关键词出现频率

并通过柱状图展示关键词分布。

------------------------------------------------------------------------

### 5. 词云可视化

利用 `WordCloud` 生成中文词云。

特点：

-   高频词显示更大
-   低频词显示较小
-   直观展示文本主题
