# 中文新闻文本分析与词云生成

## 项目简介

本项目使用 Python
对网络新闻文本进行自动化获取、文本清洗、中文分词以及词云可视化分析。

程序首先通过网络请求获取指定新闻网页内容，然后从 HTML
页面中提取正文信息，去除网页标签、图片链接以及无关符号，利用 `jieba`
中文分词工具对文本进行切分，最后统计文本关键词并生成中文词云图，用于直观展示新闻文本中的高频词汇。

------------------------------------------------------------------------

## 实现功能

-   自动请求网页并获取新闻 HTML 内容
-   从网页结构中提取文章正文
-   清理 HTML 标签和图片信息
-   去除中文标点及特殊字符
-   使用 jieba 进行中文分词
-   根据分词结果生成词云图
-   可视化展示文本关键词分布

## 代码流程

### 1. 导入相关库

程序使用以下 Python 库：

-   `requests`：获取网页内容
-   `jieba`：中文文本分词
-   `re`：正则表达式处理 HTML 内容
-   `wordcloud`：生成词云
-   `matplotlib`：显示可视化结果

------------------------------------------------------------------------

### 2. 获取新闻网页

程序通过 `requests.get()` 请求目标新闻网页：

``` python
url = "新闻网页地址"
a = requests.get(url)
```

获取网页 HTML 源代码，并保存为待处理文本。

------------------------------------------------------------------------

### 3. 提取新闻正文

利用 HTML 标签结构定位文章正文区域：

-   提取 `<div class="content-article">` 中的内容
-   删除网页中的作者信息和无关区域

------------------------------------------------------------------------

### 4. 文本清洗

对原始 HTML 文本进行处理：

-   删除 HTML 标签
-   删除图片标签
-   删除标题标签
-   去除网页格式字符

同时建立中文及英文标点符号列表，过滤无意义字符。

------------------------------------------------------------------------

### 5. 中文分词

使用 `jieba.cut()` 对新闻正文进行分词：

``` python
words = jieba.cut(text, cut_all=True)
```

将文本拆分为独立词语，并过滤掉标点等无效字符。

------------------------------------------------------------------------

### 6. 生成词云

使用 `WordCloud` 根据词频生成可视化图像。

主要参数：

-   最大字体大小：300
-   最大显示词数：500
-   背景颜色：白色
-   图片尺寸：1200 × 800
-   中文字体：simhei.ttf

最终输出新闻文本关键词词云图。

## 注意事项

1.  运行环境需要安装中文字体
    `simhei.ttf`，否则可能无法正常显示中文词云。
2.  网页 HTML
    结构可能随着网站更新发生变化，如果正文提取失败，需要重新调整 HTML
    标签定位方式。
3.  该程序主要用于文本分析学习，不建议用于大规模网页爬取。
